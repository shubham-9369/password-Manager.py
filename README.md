# 🔐 Password Manager

A simple command-line Password Manager built using Python.

This project allows users to save passwords for different websites and retrieve them whenever needed. Retrieved passwords are automatically copied to the clipboard using the Pyperclip library.

## 🔗 Project Repository

[View Project on GitHub](https://github.com/shubham-9369/password-Manager.py)

## 🚀 Features

- Save passwords for different websites
- Retrieve saved passwords
- Automatically copy passwords to clipboard
- Simple command-line interface
- Handles missing password files
- Local file-based password storage

## 🛠️ Technologies Used

- Python
- Pyperclip
- File Handling
- Functions
- Loops
- Conditional Statements
- Exception Handling
